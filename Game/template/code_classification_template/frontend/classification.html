Types of Waste

Organic Waste

Organic waste includes food scraps, garden waste, and biodegradable materials.

Recyclable Waste

Recyclable waste includes plastics, paper, metal, and glass that can be processed and reused.

Hazardous Waste

Hazardous waste includes chemicals, batteries, and medical waste that require special disposal.
